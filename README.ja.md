# tell-me-tick-me

Tell me what to do, and tick me off when it's done.

デスクトップの隅に住む **AI ネイティブな todo アプリ**です。タスクは**ただの markdown ファイル**、チェックを入れるとその日の日記に自動でアーカイブ。ウィンドウは昔の QQ メッセンジャーみたいに**画面の端に吸い付き**、マウスが触れるとスッと出てきて、離れると引っ込みます。中には AI 秘書の **Amy** が住んでいます(名前は中国語の語呂合わせ「A秘」= AI 秘書から)。最近やることを話せば、**タスクの分解、優先順位づけ、締め切りが重なったときの割り切り**まで手伝ってくれます。

## 🌱 なぜ作ったか

博士課程の学生である私の毎日は、自由度が高いぶん自己管理がすべてです。その日にやることは論文の進捗、実験の状態、プロジェクトの締め切り、そして突然降ってくる新しいタスク次第。**決まりきったリストで毎日を標準化するのは無理がありました。**

だから「今日は何をすべきか」を整理してくれるツールが欲しかったのです。進行中のプロジェクトを整理し、**今日・今週・今月・長期**を区別し、終わったことを振り返り、「思いついた順にやる」を少しでも減らす。未完了のタスクを教えてくれるだけでなく、**いま本当に進めるべきことは何か**、急ぎに見えて実は後回しでいいものはどれか、力を注ぐべきものと「ほどほどで十分」なものはどれか。それが見えるツールです。

## 🧠 タスクが多すぎるときは、AI と相談する

複数のプロジェクトの締め切りが同じ時期に重なることは、誰にでも起こります。タスクが急に積み上がると**人はパニックになりがち**です。どれから手をつけるか分からない、どこから始めればいいか分からない、全部ちゃんとやりたいばかりに、かえって何も始められない。

そんなとき私は Amy に直接相談します。最近のタスクは何か、どこで詰まっているか、前提条件があるものはどれか、時間が足りないときに力をどう配分するか。彼女はリストを並べ替えるだけではありません。**どれは 60 点で十分か、どれは 80 点まで持っていくべきか、どれに全力を注ぐ価値があるか**という、実際的な判断にまで踏み込みます。タスクが密集して余力がないときにこそ、すべてを「重要」にマークするのではなく、**冷静で現実的な選択をする**。それが目標です。

## ✨ 普通の todo アプリと何が違うか

成熟した todo アプリはすでにたくさんあります。このプロジェクトは「追加・チェック・削除ができるリスト」をもう一つ作りたいわけではありません。違いは **AI がオマケ機能ではなく、ワークフローの中心にある**こと。それは具体的な設計に表れています:

- **タスクはただの markdown ファイル**(todo.md):AI がそのまま読むので、データは常に自分の手元にあり、生活をフォームに押し込む必要がない
- **Amy はプロジェクトの背景と毎日のアーカイブを見られる**:実際の進捗に基づいてタスクを分解し、優先順位をつけ、振り返りを手伝う
- **Amy は提案するだけ。反映は必ずあなたのクリック**:追加・移動・削除の三種のカードはすべて確認待ち。彼女に todo を直接書き換える権限はない
- **Amy は自分の記憶ファイルを持つ**:あなたの働き方と長期的な目標への理解を、少しずつ育てていく

**複数のプロジェクトが並行し、スケジュールを自分で管理する**働き方なら、きっと合うと思います。

## 🚀 動かす

必要なもの:macOS(フローティングウィンドウは Mac ネイティブ。Web 部分はどの OS でも動きます)、Python 3.10+、フローティングシェルをビルドするなら Xcode コマンドラインツール。

```bash
git clone https://github.com/cyresearch/tell-me-tick-me
cd tell-me-tick-me
./run.sh
# ブラウザで http://127.0.0.1:8765 を開く
```

初回起動でサンプルの todo(`data/todo.md`)が自動生成されるので、**その場でチェックを試せます**。フローティングウィンドウを使うなら:

```bash
./shell/build.sh      # 一度だけコンパイル
./shell/TellMeTickMe  # 画面右端に吸着、マウスを近づけるとスライドアウト
```

## 🔌 自分の LLM をつなぐ(Amy の出勤)

チャットパネルを初めて開くと設定ウィザードが出ます。**三つのチャンネルから一つ**選んでください:

| チャンネル | 向いている人 | 説明 |
|---|---|---|
| **Claude Code** | Claude のサブスク利用者 | 自分の契約をそのまま使う、正規の方法。**一番フル機能**:Amy が指定ディレクトリを検索でき、自分の記憶も管理できる |
| **Anthropic API** | API key を持つ人 | key は**この端末の** `config/llm.json` にだけ保存。第三者を経由しない |
| **Ollama** | コストゼロ・完全オフライン派 | ローカルモデルで、**データが PC の外に出ない** |

**LLM をつながなくても普通に使えます**:チェック、アーカイブ、編集、吸着ウィンドウに AI は不要です。このプロジェクトは**「サブスク相乗り」型の第三者接続を一切やりません**。三つのチャンネルはすべて正面玄関です。

💡 **音声入力との併用がおすすめ**:OS の音声入力や使い慣れた音声入力ソフトで、最近のことを Amy に**話しかけて**ください。タスクの相談は、打つより喋るほうがずっと速いです。

## 🧩 相性のいい相棒:初日から Amy に自分を知ってもらう

Amy はあなたを知るほど、提案が的確になります。私はもう一つ [chatgpt-memory-extraction](https://github.com/cyresearch/chatgpt-memory-extraction) というツールも作りました。何年分もの ChatGPT 会話のエクスポートデータを、**構造化された個人の記憶アーカイブ**(タイムライン・人物・トピック)に整理するものです。生成されたアーカイブのディレクトリを Amy のペルソナファイルに書いておけば、Claude Code チャンネルで彼女が必要に応じて検索できます。**あなたの来歴も、進行中の仕事も、周りの人も、初日から知っている**。毎回自己紹介からやり直す必要はもうありません。

## ⚙️ 設定(環境変数、すべてデフォルトあり)

| 変数 | デフォルト | 意味 |
|---|---|---|
| `DESK_TODO_FILE` | `data/todo.md` | todo ファイル(自分の markdown を指定可) |
| `DESK_DAILY_DIR` | `data/daily` | 日次アーカイブのディレクトリ |
| `DESK_PORT` | `8765` | ポート |
| `DESK_BIND` | `127.0.0.1` | `0.0.0.0` で LAN 公開(共有ネットワークでは注意) |
| `TMTM_CLAUDE_MODEL` | `opus` | Claude Code チャンネルのモデル |

Amy のペルソナは `config/secretary.example.md` にあります。`config/secretary.md` にコピーして、コメントに従って自分の状況を書き込んでください(ペルソナ、Amy の記憶、LLM 設定はすべて **git に入りません**)。

## 🛡 todo.md をどう守るか

- **手編集が常に優先**:操作のたびにファイルを読み直し、ディスク上の内容が正
- **書き込みは行ブロック単位の外科手術だけ**:それ以外はバイト単位でそのまま
- 毎日最初の書き込み前に `runtime/backups/` へ**自動バックアップ**
- **すべての操作が取り消し可能**。AI の提案は必ず人間のクリックを待つ
- 項目が見つからないとき(直前に別の場所で編集された等)は操作を拒否してリロードを促す。**推測で消したりしない**
