# 睡眠管理与智能闹钟:搭建指南

这套可选功能让 Amy 参与你的睡眠:晚上道晚安、深夜查岗、用 Apple Watch 的真实睡眠数据说话,并按你**实际入睡的时间**自动设第二天的 iPhone 起床闹钟。

需要:Apple Watch(睡眠记录)、已配好的 Discord bot(见 README 的 Discord 部分)、iPhone 快捷指令。全程不装第三方 app,数据只经过你自己的 Discord 服务器。

## 全景图

```
23:30  night_call      Amy 道晚安, 请你回一句
00:30  night_escalate  一直没回音就连环 ping; 每晚记入 sleep_log
04:30  快捷指令A        手机把今晚睡眠样本发进睡眠频道
04:45  alarm_plan      按"入睡 + 目标睡眠 + 班车表"算出闹钟, 发 "ALARM hh:mm AM"
04:55  快捷指令B        读 ALARM 行, 自动创建 iPhone 闹钟
12:00  快捷指令(主导出)  完整的昨夜数据入频道
12:10  sleep_report    解析入库, DM 你一条昨夜实测
```

## 一、建睡眠数据频道

1. 在你的 Discord 服务器新建文字频道,命名 **`amy-sleep`**(程序按这个名字自动找到它;想换名字就设环境变量 `AMY_SLEEP_CHANNEL`)
2. 频道设置 → 整合 → Webhook → 新建,**复制 Webhook URL**

## 二、快捷指令:睡眠导出(4 个动作)

1. **查找健康样本**:类型=睡眠,筛选"开始日期 在最近 1 天内",按开始日期最旧优先排序
2. **重复与每个项目**:循环体内放一个「文本」动作,内容拼三个变量(英文逗号分隔):
   `重复项目·开始日期` , `重复项目·结束日期` , `重复项目·值`
   ⚠️ 两个日期的格式都选**「自定义」**,格式串 **`HH:mm`**(只要时刻;日期由消息发送时间推定,这样一晚几十段永远塞得进一条消息)
3. **合并文本**:用换行合并重复结果
4. **获取 URL 内容**:POST 到 Webhook URL,请求体表单 `content` = 合并的文本
   ⚠️ 别用"文件"类型表单字段(iOS 会静默丢掉变量,Discord 报"无法发送空白消息")

自动化:每天中午(如 12:00)运行一次 → 这是主导出。
再**复制**一份这个快捷指令,自动化挂 **04:30** → 这是给闹钟用的早导出(内容不用改)。

## 三、配置班车表

```bash
cp config/bus_schedule.example.json config/bus_schedule.json
# 填入你的真实时刻表、准备时长、目标睡眠区间
```

算法:挑第一班"醒来时刻 ≥ 入睡 + 目标下限"的车;因班次断档会睡过硬上限时退回前一班;凌晨没有数据(没戴表/还没睡)走 `no_data_fallback_alarm` 兜底。

## 四、快捷指令:自动设闹钟(6 个动作)

1. **获取 URL 内容**:GET `https://discord.com/api/v10/channels/<你的睡眠频道ID>/messages?limit=1`
   头部加一行:键 `Authorization`,值 `Bot <你的bot token>`(Bot 后面有空格)
2. **从列表获取项目** → 首个项目
3. **获取词典值** → 键 `content`
4. **匹配文本** → 正则 **`(?<=ALARM )\d{1,2}:\d{2} [AP]M`**(时刻带 AM 才不会被 iOS 解析成晚上;没有 ALARM 行时匹配为空,不会误设)
5. **从匹配获取第一项**
6. **创建闹钟** → 时间选「第一项」,起个标签如 "Amy ⏰"

自动化:每天 **04:55** 运行。

## 五、定时器(mini/Mac 侧)

用 launchd 或 cron 挂四个例程(示例时刻可改):

| 时刻 | 脚本 |
|---|---|
| 23:30 | `routines/night_call.py` |
| 00:30 | `routines/night_escalate.py` |
| 04:45 | `routines/alarm_plan.py` |
| 12:10 | `routines/sleep_report.py` |

环境变量与 Discord 值班员相同(`AMY_DISCORD_TOKEN` / `AMY_DISCORD_USER` 等)。

## 六、豁免:跟 Amy 说一声就行

哪天不想要闹钟(休息日、想睡到自然醒),**直接跟 Amy 说**"明早不用设闹钟",她会输出一个豁免指令,当晚的计算员自动跳过(一次性,只管那一个早晨)。反悔了再说一句"还是要闹钟"即可。

## 已知边界

- 快捷指令的健康筛选最小单位是"天",早导出会带旧片段;程序按"夜"分组并丢弃未来时刻的幻影,不受影响
- 一晚都没戴表:晨报如实说没有记录,闹钟走兜底
- 时刻表是平日版的话,周末班次差异需自行留意
